# Маленький пором · Урок 15

Інтерактивний україномовний урок англійської за наданими матеріалами Funny Stories, с. 66–69.

## Можливості
- П’ять занять із прогресом у localStorage.
- Вірш із трьома режимами запам’ятовування.
- Казка з перекладом речень і 68 аудіофрагментами.
- 31 картка зі словами, пошук, фільтри, перемішування.
- Запитання, True/False, had/was, зайве слово, порядок подій.
- Оригінальний запис учительки з часовими переходами.

## Локальний запуск
```sh
python3 -m http.server 8080 --directory dist
```
Відкрити http://localhost:8080. Сайт статичний, без збірки та залежностей.

## GitHub Pages
Settings → Pages → Deploy from a branch → main → /docs → Save.
Папка `docs/` — точна копія `dist/` для GitHub Pages.
Очікувана адреса: https://myrozu.github.io/lesson-15/

## Sites
Маніфест `.openai/hosting.json` задає `dist/` як статичну папку.

## Матеріали
Надані користувачем текст, фото сторінок, аудіо вчительки та окремі аудіозаписи. Публікація не додає ліцензії на оригінальний навчальний матеріал. Сторінка 70 не надана; додаткові вправи не замінюють вправи 2–5 у книжці. Прогрес зберігається лише у браузері.
